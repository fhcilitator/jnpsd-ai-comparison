Who fixes it

All three options run on Linux

Every option uses Proxmox, a Linux-based server platform. Day-to-day work happens in a web browser, but repairing a failed server and restoring it under pressure takes Linux skill our IT staff may not have yet.

TaskHow it's doneSkill
Add an agent or web appWeb interfaceLow
Check that backups ranWeb interface, plus email alertsLow
Restore one deleted app or fileWeb interfaceLow to medium
Replace a failed driveSwap the drive, then rebuild from the web interfaceMedium
Rebuild a failed server and restore everythingReinstall Proxmox, reconnect storage, restore every agent and appHigh

Why this favors the top tier

With the top tier, a hardware failure is not an emergency: work moves to the twin server automatically, and IT can replace the part during normal hours. With Options 2 and 3, the same failure stops every agent until staff repair the hardware and restore from backup, the hardest task in the table, done while leaders wait.

Our plan for any option
  • Mike Vincent serves as the primary administrator; he runs this same platform today.
  • Train at least two IT staff on the routine tasks above.
  • Write step-by-step runbooks for drive replacement and restores, and practice a restore before going live.
  • Consider a paid Proxmox subscription, which adds support tickets with Proxmox engineers.

Our recommendation

Approve the top tier

The top tier costs more up front, but it is the only option where a hardware failure does not stop the district's AI work, and the only one built for growth.

Room to grow

Two servers' worth of processing and memory for more agents, more web apps and local AI, without buying another machine.

No emergencies

Automatic failover turns a hardware failure into scheduled maintenance, so staff are never restoring from backup while leaders wait.

Inside the budget

$19,830 fits the $10K–$20K budget. If budget forces a smaller start, Option 2 is the minimum, and it can grow into the top tier later.
