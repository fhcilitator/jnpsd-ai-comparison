The main trade-off in this option

What happens when the server crashes

With one server there is no twin to take over automatically. Work pauses until the server is fixed, then everything comes back from the backup box. Data is protected; time is what we give up.

  1. Every few hours

    Restore points

    The backup box saves a restore point of every agent and app every few hours during the school day and again each night.

  2. The crash

    Agents pause

    If the server fails, the agents and web apps stop. Nobody's files are lost; the latest copy is already on the backup box.

  3. Repair

    Fix the part

    Most failures, like a power supply or a memory stick, are a same-day or next-day fix with parts from Newegg.

  4. Restore

    Back in business

    We restore from the latest restore point. Typical recovery is a few hours to a day, losing only changes made since that restore point.

Worst case

If the motherboard itself dies, a replacement is special order and can take 1–3 weeks. In that case the most important agents can be restored onto the backup box and run there, at reduced capacity, until the server is repaired.

From the video: when the server crashes the agents pause, and the backup box still holds the restore points. Drive failures are different: every file is written to two drives at once, so a dead drive costs nothing and the server keeps running.

Two ways to pay, and they can be combined

Paying for AI usage

Either way, the cost is one shared district budget for the agents the group uses, not a separate bill for every person.

Option A · Pay as you go

API credits

The district prepays credits with each AI company: Anthropic for Claude, OpenAI for GPT, xAI for Grok. Every agent and app draws from that shared pool.

Strengths
  • Works with every major model, including Claude
  • Hard dollar limits per agent, team or project
  • Usage reports show where the money goes
Watch for
  • Cost rises and falls with how much the agents work
  • Needs a monthly look at the usage report
Option B · Flat monthly fee

Subscription sign-in

A paid account such as ChatGPT or SuperGrok is linked to an agent by signing in with that account (OAuth). No API key is needed.

Strengths
  • Fixed, predictable price per account
  • A usage allowance is included in the fee
Watch for
  • Allowances can run out before the month ends
  • Accounts are meant for one person, so sharing one across a group may break the terms
  • Claude subscriptions can't be used this way; Anthropic limits them to its own apps
Recommendation

Start with a pooled API budget for shared agents and district apps. Add district-paid subscription accounts only for individual leaders whose own agents need heavy daily use, after checking each plan's terms.
